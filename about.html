About this project

What this is

PyBench is a self-contained coding platform built for GCSE Computer Science students. It contains 50 Python programming challenges, arranged into eight levels that rise gradually from an absolute-beginner print() statement through to full projects that combine several concepts at once.

The focus throughout is on learning by solving problems, not by reading theory — each challenge gives you a clear brief and requirements, and then gets out of the way so you can write and run real code.

Who it's for

It's aimed at students aged roughly 14–16 studying GCSE Computer Science, and can be used for independent practice or as evidence of self-directed programming work to show a teacher — the Progress and Teacher View pages are designed with that in mind.

How it works

Everything runs entirely in your browser. Python code is executed by Pyodide, a full Python interpreter compiled to run on the web, so there's no server and nothing to install. Your progress, saved code and completed challenges are stored locally on your device using your browser's storage — they aren't uploaded anywhere, and they won't follow you to a different browser or computer.

How challenges are structured

Every challenge includes a description, a checklist of requirements, the GCSE concepts it covers, a set of progressively more specific hints, and a hidden model solution with an explanation. Where practical, challenges also include automated tests that check your program's output directly.
